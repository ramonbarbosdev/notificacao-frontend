Política de Privacidade da API

Última atualização: 24 de agosto de 2026

Esta Política de Privacidade descreve como a [NOME DA EMPRESA], inscrita no CNPJ sob nº [CNPJ], por meio da [NOME DA API] ("API", "Plataforma", "Serviço" ou "Sistema"), coleta, utiliza, armazena, protege e eventualmente compartilha dados pessoais.

Esta Política foi elaborada em conformidade com a Lei nº 13.709/2018 – Lei Geral de Proteção de Dados Pessoais (LGPD) e demais normas aplicáveis à proteção de dados pessoais.

Ao utilizar a API ou integrar sistemas, aplicações e serviços à API, o usuário declara estar ciente das práticas descritas nesta Política.

1. Definições

Para fins desta Política:

  • API: interface disponibilizada pela [NOME DA EMPRESA] para integração entre sistemas e serviços.
  • Usuário: pessoa física que utiliza a API ou possui credenciais de acesso.
  • Cliente: pessoa física ou jurídica que contrata ou utiliza os serviços da [NOME DA EMPRESA].
  • Dados pessoais: qualquer informação relacionada a uma pessoa natural identificada ou identificável.
  • Titular: pessoa natural a quem os dados pessoais se referem.
  • Tratamento: toda operação realizada com dados pessoais, incluindo coleta, acesso, armazenamento, utilização, transmissão e eliminação.
  • Controlador: pessoa natural ou jurídica responsável pelas decisões referentes ao tratamento dos dados pessoais.
  • Operador: pessoa natural ou jurídica que realiza o tratamento de dados pessoais em nome do controlador.

2. Escopo

Esta Política aplica-se aos dados pessoais tratados por meio da API e dos serviços relacionados disponibilizados pela [NOME DA EMPRESA].

A API poderá ser utilizada por clientes para integração com sistemas próprios ou de terceiros.

Quando o cliente utilizar a API para tratar dados pessoais de seus próprios usuários, clientes, funcionários ou terceiros, o cliente poderá atuar como Controlador, enquanto a [NOME DA EMPRESA] poderá atuar como Operadora, conforme a natureza da operação e as responsabilidades definidas contratualmente.

3. Dados pessoais tratados

Dependendo dos serviços utilizados e da integração realizada, a API poderá tratar as seguintes categorias de dados:

3.1. Dados cadastrais

  • Nome;
  • CPF ou CNPJ;
  • Endereço;
  • Telefone;
  • Endereço de e-mail;
  • Informações profissionais;
  • Dados de identificação da organização;
  • Outros dados fornecidos voluntariamente pelo cliente.

3.2. Dados de autenticação

  • Identificador do usuário;
  • Credenciais de autenticação;
  • Tokens de acesso;
  • Identificadores de sessão;
  • Informações relacionadas à autenticação;
  • Registros de acesso.

Senhas, quando aplicável, são armazenadas utilizando mecanismos de proteção criptográfica adequados, não sendo mantidas em formato de texto puro.

3.3. Dados técnicos

Durante a utilização da API poderão ser registrados dados técnicos necessários para segurança, operação e monitoramento, incluindo:

  • Endereço IP;
  • Data e hora das requisições;
  • Endpoint acessado;
  • Método HTTP utilizado;
  • Código de resposta;
  • Identificadores de requisição;
  • Informações do dispositivo ou aplicação cliente;
  • Informações do navegador ou agente de usuário;
  • Registros de erros e eventos técnicos.

3.4. Dados enviados pelo cliente

A API poderá processar dados enviados pelo próprio cliente durante as requisições.

Esses dados podem variar de acordo com a finalidade da integração e poderão conter dados pessoais de terceiros.

O cliente é responsável por garantir que possui base legal adequada para o tratamento e compartilhamento desses dados com a API.

4. Finalidades do tratamento

Os dados pessoais poderão ser tratados para as seguintes finalidades:

  • Disponibilizar e executar os serviços contratados;
  • Autenticar usuários e aplicações;
  • Controlar acesso a recursos da API;
  • Processar requisições;
  • Realizar integrações entre sistemas;
  • Manter a segurança da plataforma;
  • Prevenir fraudes, abusos e acessos não autorizados;
  • Monitorar disponibilidade e desempenho;
  • Identificar e solucionar falhas técnicas;
  • Manter registros e trilhas de auditoria;
  • Cumprir obrigações legais e regulatórias;
  • Atender solicitações dos usuários e clientes;
  • Exercer direitos em processos administrativos, judiciais ou arbitrais;
  • Melhorar a qualidade, segurança e confiabilidade dos serviços.

5. Bases legais

O tratamento de dados pessoais poderá ocorrer com fundamento nas hipóteses previstas na LGPD, incluindo, conforme aplicável:

  • Execução de contrato ou procedimentos preliminares;
  • Cumprimento de obrigação legal ou regulatória;
  • Exercício regular de direitos;
  • Legítimo interesse;
  • Consentimento do titular;
  • Proteção da vida ou da incolumidade física;
  • Demais hipóteses previstas na legislação aplicável.

6. Dados enviados por clientes através da API

Quando um cliente utilizar a API para armazenar, transmitir ou processar dados pessoais de terceiros, o cliente será responsável por:

  • Garantir a existência de base legal adequada;
  • Informar os titulares sobre o tratamento realizado;
  • Respeitar os direitos previstos na LGPD;
  • Garantir que os dados enviados sejam adequados, pertinentes e necessários;
  • Evitar o envio de dados pessoais desnecessários;
  • Manter suas credenciais de acesso protegidas;
  • Comunicar incidentes relacionados às suas próprias aplicações quando aplicável.

A [NOME DA EMPRESA] poderá tratar esses dados conforme as instruções legítimas do cliente e as condições estabelecidas contratualmente.

7. Dados pessoais sensíveis

A API poderá, dependendo da utilização realizada pelo cliente, receber dados pessoais sensíveis.

A [NOME DA EMPRESA] não solicita o envio de dados pessoais sensíveis quando esses dados não forem necessários para a execução do serviço.

O cliente deverá evitar o envio de dados pessoais sensíveis, informações financeiras completas, credenciais, senhas ou quaisquer informações desnecessárias para a finalidade da integração.

8. Dados financeiros e informações de pagamento

Quando houver funcionalidades relacionadas a pagamentos, a API poderá utilizar serviços especializados de terceiros para processamento e tokenização de informações financeiras.

Importante: dados como número completo do cartão e código de segurança não deverão ser armazenados diretamente pela [NOME DA EMPRESA], sempre que o processamento puder ser realizado por um provedor especializado.

As informações necessárias para processamento poderão ser substituídas por identificadores ou tokens fornecidos pelo provedor de pagamento.

9. Compartilhamento de dados

Os dados pessoais poderão ser compartilhados somente quando necessário para a execução das finalidades previstas nesta Política.

Isso poderá incluir:

  • Provedores de infraestrutura;
  • Provedores de hospedagem;
  • Serviços de armazenamento;
  • Provedores de autenticação;
  • Serviços de monitoramento;
  • Provedores de pagamento;
  • Serviços de comunicação;
  • Empresas responsáveis por suporte técnico;
  • Prestadores de serviços necessários à operação;
  • Autoridades públicas, quando houver obrigação legal ou determinação válida.

A [NOME DA EMPRESA] não comercializa dados pessoais como produto.

10. Transferência internacional de dados

Alguns fornecedores utilizados na operação da API poderão estar localizados fora do Brasil ou utilizar infraestrutura localizada no exterior.

Quando houver transferência internacional de dados pessoais, a [NOME DA EMPRESA] adotará mecanismos compatíveis com as exigências da LGPD e da regulamentação aplicável.

11. Segurança da informação

A [NOME DA EMPRESA] adota medidas técnicas e administrativas destinadas a proteger os dados pessoais contra acessos não autorizados, destruição, perda, alteração, comunicação indevida, vazamento e tratamento inadequado ou ilícito.

Entre as medidas de segurança poderão ser utilizadas:

  • Criptografia durante a transmissão de dados;
  • Controle de acesso baseado em permissões;
  • Autenticação segura;
  • Tokens de acesso;
  • Segregação de ambientes;
  • Monitoramento de infraestrutura;
  • Registros de auditoria;
  • Mecanismos de proteção contra abuso;
  • Backups controlados;
  • Políticas de controle de acesso;
  • Atualização de componentes de infraestrutura;
  • Medidas de isolamento entre clientes e organizações, quando aplicável.

Nenhum sistema é absolutamente seguro. Embora sejam adotadas medidas técnicas e administrativas apropriadas, não é possível garantir segurança absoluta contra todos os eventos existentes no ambiente digital.

12. Multi-tenant e isolamento de dados

Quando a API utilizar arquitetura multi-tenant, serão adotadas medidas destinadas a impedir que dados de uma organização sejam acessados indevidamente por outra organização.

Os mecanismos de autorização deverão considerar, conforme aplicável:

  • Identificação da organização;
  • Usuário autenticado;
  • Permissões;
  • Recursos autorizados;
  • Contexto da requisição;
  • Escopo do tenant.

Tentativas de acesso a recursos pertencentes a outra organização poderão ser registradas e bloqueadas pelos mecanismos de segurança da plataforma.

13. Retenção dos dados

Os dados pessoais serão mantidos pelo período necessário para:

  • Execução dos serviços;
  • Cumprimento das finalidades informadas;
  • Cumprimento de obrigações legais ou regulatórias;
  • Exercício regular de direitos;
  • Prevenção de fraudes e incidentes;
  • Manutenção de registros técnicos e de auditoria.

Após o término do período necessário, os dados poderão ser eliminados, anonimizados ou mantidos quando houver fundamento legal que permita sua conservação.

14. Exclusão de dados

O titular poderá solicitar a eliminação de seus dados pessoais, observadas as hipóteses e limitações previstas na LGPD.

A eliminação poderá não ocorrer quando a conservação for necessária para:

  • Cumprimento de obrigação legal ou regulatória;
  • Exercício regular de direitos;
  • Cumprimento de contrato;
  • Prevenção à fraude;
  • Atendimento de determinação de autoridade competente;
  • Outras hipóteses legalmente permitidas.

15. Direitos dos titulares

Nos termos da LGPD, o titular poderá solicitar, conforme aplicável:

  • Confirmação da existência de tratamento;
  • Acesso aos dados pessoais;
  • Correção de dados incompletos ou desatualizados;
  • Anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desconformidade;
  • Portabilidade dos dados, quando aplicável;
  • Informação sobre compartilhamentos;
  • Informação sobre as consequências do não fornecimento de consentimento;
  • Revogação do consentimento;
  • Oposição ao tratamento quando cabível;
  • Revisão de decisões automatizadas, quando aplicável.

16. Cookies e tecnologias similares

A API, por sua natureza técnica, poderá utilizar identificadores, tokens, logs e tecnologias necessárias para autenticação, segurança, funcionamento e monitoramento dos serviços.

Quando houver aplicações web associadas à API, poderão ser utilizados cookies ou tecnologias similares para funcionalidades de sessão, segurança, preferências e análise técnica.

17. Logs e auditoria

Para garantir segurança, rastreabilidade e estabilidade dos serviços, a API poderá registrar eventos relacionados às requisições.

Os registros poderão conter:

  • Identificador da requisição;
  • Data e hora;
  • Endereço IP;
  • Usuário ou aplicação responsável;
  • Endpoint;
  • Resultado da operação;
  • Informações técnicas relacionadas ao processamento;
  • Eventos de segurança.

A [NOME DA EMPRESA] deverá evitar o armazenamento de dados pessoais desnecessários em logs.

Informações sensíveis, credenciais, senhas, tokens secretos e dados financeiros completos não deverão ser registrados em logs de aplicação.

18. Incidentes de segurança

Caso ocorra um incidente de segurança envolvendo dados pessoais, a [NOME DA EMPRESA] adotará as medidas necessárias para avaliar, conter, investigar e mitigar seus efeitos.

Quando aplicável, serão realizadas as comunicações exigidas pela legislação e pela regulamentação da Autoridade Nacional de Proteção de Dados – ANPD.

19. Responsabilidades do cliente

O cliente que utilizar a API é responsável pelos dados que inserir, transmitir ou processar por meio dos serviços.

O cliente deverá:

  • Utilizar a API de acordo com a legislação aplicável;
  • Proteger suas credenciais;
  • Não compartilhar tokens ou chaves secretas;
  • Implementar controles de acesso adequados;
  • Coletar somente os dados necessários;
  • Possuir base legal para tratamento dos dados;
  • Informar os titulares quando necessário;
  • Comunicar incidentes relacionados ao seu ambiente;
  • Não utilizar a API para finalidades ilícitas.

20. Uso aceitável da API

É proibido utilizar a API para:

  • Praticar atividades ilícitas;
  • Tentar obter acesso não autorizado;
  • Explorar vulnerabilidades;
  • Comprometer a infraestrutura;
  • Realizar ataques de negação de serviço;
  • Distribuir malware;
  • Coletar dados pessoais sem autorização ou base legal;
  • Utilizar credenciais de terceiros;
  • Contornar mecanismos de segurança;
  • Violar a legislação aplicável.

A [NOME DA EMPRESA] poderá suspender ou bloquear acessos que representem risco à segurança da plataforma ou violação dos termos de utilização.

21. Serviços de terceiros

A API poderá depender de serviços de terceiros para infraestrutura, armazenamento, autenticação, comunicação, monitoramento, pagamentos ou outras funcionalidades.

Esses serviços poderão possuir suas próprias políticas de privacidade e termos de uso.
