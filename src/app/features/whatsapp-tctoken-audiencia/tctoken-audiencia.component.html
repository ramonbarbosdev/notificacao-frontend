Como funciona
  • Entram responsáveis GitHub ativos e destinatários com notificação WhatsApp na fila nos últimos {{ scan()?.filaLookbackDias ?? 60 }} dias.
  • Idade e dias restantes vêm do gateway para números em uso: GitHub ativo ou com envio WhatsApp nos últimos 30 dias (configurável). Demais entradas da fila aparecem na lista, sem consulta ao gateway.
  • Com sessão conectada, a API enriquece automaticamente (no máximo a cada 5 min). Use Atualizar para forçar.
  • Isso não é opt-in de produto: se o token expirar, alertas podem parar de ser entregues.
  • Pedir confirmação envia mensagem manual (máx. 1 a cada 7 dias por número). A resposta inbound renova conversa/token — não substitui opt-in GitHub. Se o envio falhar (sem token), use Copiar link wa.me.
  • Administradores podem usar modo teste no modal quando o envio normal está bloqueado: envia mesmo assim, sem o limite de 7 dias (mensagem prefixada [TESTE ADMIN]).
