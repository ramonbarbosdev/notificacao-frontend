WhatsApp / Integrações

Conecte seus sistemas ao WhatsApp

Duas formas de envio — escolha conforme o caso de uso da sua organização.

Gateway (sessão / QR)

Ideal para conversas, envios rápidos e operações que usam sessão WhatsApp Web. Cada organização mantém sua própria sessão isolada.

Meta Cloud API

Integração oficial com templates aprovados, webhook de entrega e Embedded Signup. O custo de mensagens é faturado pela Meta na conta Business do cliente.

API REST

Envie notificações simples ou por template usando API key — integre PHP, Node, Java ou qualquer backend HTTP.

Webhooks

Receba eventos de status e integre com CRMs, ERPs ou automações internas.

  • Documentação de envio simples e por template no painel
  • Webhook Meta em /api/webhooks/whatsapp/meta
  • Feature flags para habilitar Gateway e/ou Cloud por organização
